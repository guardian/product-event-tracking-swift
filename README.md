This repository holds the product event tracking models generated by the [product-events-registry](https://github.com/guardian/product-events-registry) repository. 

When updates are made to the shared definition file a Github workflow runs which generates the models and creates a PR in this repository. 


### Releases 
On merging a PR into main to update models you should manually [generate a release](https://github.com/guardian/product-event-tracking-swift/releases/new).
